# delivery-order-platform
Python Flask와 MySQL을 연동하여 고객·사장·라이더가 사용하는 배달 음식 주문 웹 서비스를 개발합니다.

## 주요 개발 기능

- **고객**: 가게·메뉴 조회, 장바구니 관리, 주문, 주문 내역 조회, 리뷰 작성
- **사장**: 메뉴·옵션 관리, 주문 접수, 매출 통계 조회
- **라이더**: 배차 대기 주문 조회, 배차 수락, 배달 완료 처리

## 기술 스택

- **언어**: Python 3.12
- **웹 프레임워크**: Flask 3.1
- **화면**: HTML, CSS
- **데이터베이스**: MySQL 8.4 LTS · InnoDB
- **DB 연결**: MySQL Connector/Python
- **DB 모델링 및 관리**: MySQL Workbench

## 프로젝트 목표

ERD 설계와 정규화를 바탕으로 데이터베이스를 구축하고,
SQL·제약조건·트랜잭션·VIEW·트리거를 웹 서비스에 적용합니다.

- 개발 인원: 5명
- 개발 기간: 약 4주
- 활용 데이터: 행정안전부 착한가격업소 현황
